# Customer Support RAG Assistant

A document-based AI assistant that retrieves relevant customer-support
information and generates context-aware answers.

## Project Goals

- Load and process customer-support documents.
- Split documents into searchable chunks.
- Retrieve relevant passages for user questions.
- Generate answers grounded in retrieved information.
- Expose the assistant through a FastAPI endpoint.
- Evaluate retrieval and answer quality.

## Tech Stack

- Python 3.12
- LLMs and embeddings
- FastAPI
